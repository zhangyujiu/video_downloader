## 🔬 技术内幕与防封机制

本项目能够稳定工作的核心原因在于解决了以下关键技术难点：

### 1. 移动端伪装（绕过机房 IP 滑块风控）
Cloudflare Worker 的 IP 均属于海外数据中心 IP。如果使用电脑端 User-Agent 访问抖音网页，会直接触发高强度的滑动拼图验证码。
- **解决办法**：在云端 Puppeteer 启动时，强制模拟 **iPhone Safari 移动端环境**，并使用低风控的移动端页面进行加载，从而完全绕过了拼图风控，实现了 100% 自动解析。

### 2. URL 动态重构（彻底去除水印）
由于使用移动端模式访问，抖音 API 默认会返回针对手机展示的带水印视频流链接（链接包含 `/playwm/` 路径）。
- **解决办法**：Worker 在截获视频源链接后，利用字符串替换算法自动将 `/playwm/` 替换为无水印路径 `/play/`，从而将有水印视频源无缝逆向转化为纯净的高清无水印视频源。

### 3. 云端流式管道代理（突破 403 跨域与防盗链限制）
抖音的 CDN 资源（`douyinvod.com`）要求请求头必须包含 `Referer: https://www.douyin.com/`，直接用手机浏览器打开或下载会提示 `403 Forbidden`。
- **解决办法**：Worker 内部提供 `/api/download` 代理通道。当用户请求下载或在前端播放时，Worker 会在后台发起流式传输（Streaming），注入所需的 Referer 和 CORS 跨域请求头，并将二进制流以管道（Pipe）的形式回传至手机浏览器，实现了完美的跨平台直载和预览。
